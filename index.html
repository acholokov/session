2. В SQL Editor выполните скрипт создания таблицы app_state.
3. Скопируйте URL проекта и anon key (Settings → API) в константы в начале кода.
4. Чтобы входить сразу после регистрации, снимите Confirm email (Authentication → Providers → Email).
